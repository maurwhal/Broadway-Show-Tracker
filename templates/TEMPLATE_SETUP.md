# Broadway-Show-Tracker Template

## Getting Started

### 1. Copy the Template Google Sheet

[**Open Broadway-Show-Tracker_Template**](https://docs.google.com/spreadsheets/d/1JSkcN7KjiUQ6ezgjsCS0jrn7aD6MFKuXKpBRxqvqZnU/edit?usp=sharing)

Click **File → Make a copy** to get your own editable version.

### 2. Reference Files

This folder contains CSV exports showing the template structure:
- `BWAY 41.csv` — Main theatre tracker schema
- `Shows Booked.csv` — Show attendance log schema

Use these to understand the layout, but use the live Google Sheet (link above) for actual setup.

### 3. Next Steps

- Follow the main [README](../README.md) for script setup
- Add your Apps Scripts to your copied sheet
- Set up triggers and customize API keys
